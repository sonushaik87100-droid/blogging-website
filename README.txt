How to run
----------
1. Extract the ZIP.
2. Keep the images folder in the same folder as index.html.
3. Open index.html in Chrome/Edge/Firefox.
4. Login with the demo credentials.
5. Search the 10 foods using the dashboard search box.

Important
---------
This is a front-end educational demo. The login credentials are stored in JavaScript,
so it is NOT a secure production authentication system.

The food descriptions are based on references from NITI Aayog's 2026
"Divya Bharat: A Window to the Soul of India" and other culinary references.
